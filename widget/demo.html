Demo Business

This page stands in for a customer's existing website. It could be WordPress, Shopify, Webflow, or hand-written HTML like this — it doesn't matter. The chat bubble in the bottom-right corner is injected by one script tag, exactly the way Intercom or Tawk.to embed on any site.

Before this works: start the backend locally (see the root README.md), then create a business via POST /auth/signup with the name Demo Business — that slugifies to demo-business, matching the data-business-id below. Configure its FAQs/services with PUT /businesses/me/chatbot-config before chatting.
